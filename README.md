# SmartFix

## Everyday Problem, Smart Solution

SmartFix is a service-finding platform designed to help people solve common everyday problems.

Users will be able to describe a problem and find the appropriate service provider.

## Project Goal

The goal is to make finding everyday services simple, fast and smart.

Examples:

- Leaking tap → Plumber
- Broken laptop → Computer & Laptop Technician
- Refrigerator not cooling → AC / Fridge Technician
- Electrical problem → Electrician

## Current Features

- Landing page
- Problem description input
- Service categories
- How it works section
- Responsive design
- Initial JavaScript interaction

## Planned Features

- AI-powered problem classification
- Gemini API integration
- Nearby service providers
